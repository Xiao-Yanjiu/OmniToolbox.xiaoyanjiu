# 双平台音乐播放器 1.3.4 本地版

在 Omni 本地模块中使用本目录的 **MusicPlayer.cs**，重新加载或停用后再启用已有的音乐播放器。不要同时启用另一个来源的同名模块。后续继续修改此文件，未更新 GitHub 在线清单。

## 使用

打开原来的音乐曲库窗口，在“账号登录”旁的下拉框选择 QQ音乐或网易云音乐。登录、搜索、推荐、收藏、播放列表、当前歌曲和悬浮窗随选择显示，全部沿用原来的主题与控件。

两边的账号、喜欢列表、歌单缓存、队列、当前歌曲、音量、歌词及播放设备分别维护。切换页面不停止另一平台的音乐，所以两边同时播放时会叠加出声；在对应平台点击暂停可分别控制。设置窗口也对应当前选择的平台。

网易云使用其 App 扫码确认；二维码过期或取消后可重新生成。喜欢/取消喜欢会修改当前网易云账号的收藏，仅在接口返回成功后更新显示。

网易云已接入：单曲搜索、热歌/新歌/飙升/原创榜、二维码登录、我喜欢、账号歌单和完整曲目读取、喜欢/取消喜欢、歌词、封面及标准音质 MP3 播放。无版权、仅试听或当前不支持的编码会显示原因。会员权益取决于登录账号；暂未加入无损/FLAC/YRC 逐字歌词。

音频处理：QQ 保留原后端；网易云 MP3 由内置纯 C# 解码器转换为临时 PCM WAV，再通过独立的系统播放设备播放。无需安装 Node、网易云桌面客户端或外部解码服务。完整下载和解码完成后才开始播放，长歌曲首次等待可能更明显；切歌会取消过期下载，播放关闭后清理当前临时文件。

## 构建

`dotnet build MusicPlayer.csproj -c Release`

可通过 `-p:DalamudLibPath=实际目录` 和 `-p:OmniLibPath=实际目录` 指定依赖。当前验证使用 Dalamud CN 26-10-18-01、Omni 1.1.7.5、.NET 10。检查项目位于 Tests，默认不会访问网络；加 `--live --audio` 才执行匿名请求及静音音频检查。

## 悬浮窗宏

先启用音乐播放器模块，使用以下唯一命令打开或关闭当前所选音乐平台的悬浮窗：

```
/MusicPlayer
```

无需参数，不影响歌曲播放。模块启用时注册命令，停用时注销；不接管 Omni 命令。
界面及说明已移除旧命令和独立显示、隐藏用法。
