# IChing 0.6.1

- 修正钓鱼动画速度只写入整体缓存、没有正确应用的问题；改用本人基础与上半身动画槽的原生 SetSlotSpeed，使用单开关，并显示附近玩家暂停状态。
- 最大加速度与移速分开管理，快速结印不再要求先开启复唱缩减。只开快速结印时保留其他技能原来的复唱时间。
- 停用时先取消回调，再分别恢复和释放资源；单项托管清理失败后继续执行其余步骤。
- 隐私文字刷新限制为最多每100ms一次，补充未建立的 HUD 内部组件检查。

保留旧配置字段以兼容已有配置。钓鱼仍为本地快速播放实现，不等同于已完整还原原版资源替换，也不缩短服务器等待。

使用 Dalamud CN 26-10-18-01 与 Omni 1.1.7.5 编译通过，0错误0警告。托管回归包含1000帧速度模拟、16组开关组合、复唱边界与清理异常注入；尚未完成游戏内效果验证。

本次仅发布模块源码与说明，不包含原版 I-Ching-GL.dll 或其受保护实现。
