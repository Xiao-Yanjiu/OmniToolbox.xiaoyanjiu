# 狒狒食柿 App 0.3.56 验证版

本次仅更新 App；服务端保持 0.3.55，硬件串流组件及 FFmpeg 不变。

- 小窗改为28像素高的单行标题栏，缩短按钮文字并保留完整辅助标签；标题栏始终位于视频外，不再因小窗变窄换成竖排。
- 小窗与分屏的缩放手柄改为视频下方独立细条，移除覆盖在画面上的右下箭头。原生视频按实际内容区布局，标题与缩放条均不侵入画面。
- 小窗映射面板展开后位于视频下方，允许滚动，不覆盖视频；窗口缩放后继续保持画面比例。
- 触屏模式不绘制手机鼠标指针；仅在鼠标模式显示服务端反馈的指针。
- 取消每次触摸时将鼠标指针重置到中央；继续从上次位置移动。操作期间及短暂收尾阶段忽略迟到的位置反馈，避免旧坐标覆盖正在移动的指针。

验证：浏览器回归通过，覆盖160像素宽小窗标题按钮不换行、标题/视频/缩放条几何隔离、原生视频内容边界、映射面板不遮挡、触屏无指针及新手势不回中。APK签名与打包资源一致性检查通过。实际手机显示和游戏指针行为待更新核对。

当前连接仍为手机直连电脑的HTTPS/TLS H.264传输，不经过本项目中转服务器；未提供自动NAT穿透或WebRTC会话协商。
