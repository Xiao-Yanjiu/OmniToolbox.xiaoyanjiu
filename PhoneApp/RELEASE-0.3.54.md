# 狒狒食柿 0.3.54 验证版

请同时更新 App 和服务端。继续使用 0.3.53 硬件串流组件及已有 FFmpeg，无须重新下载组件。

- 修复静止鼠标心跳反复注入移动、按下和松开事件，避免拉回电脑指针或干扰实体鼠标。
- 鼠标指针模式改用相对移动；开始触摸不再跳回旧绝对坐标，点击不额外移动鼠标。触屏模式保留画面绝对定位。
- 按键请求只保留一个在途请求，完成后发送最新状态，避免网络积压后重放旧移动。键盘与鼠标独立发送，旧会话和旧控制模式的迟到请求被拒绝。
- 串流默认只看画面；点击“控制”才发送手机输入。“只看”、隐藏控制、切换显示模式、切后台或失去前台权限时退出控制，避免与电脑操作混用。
- 服务端串流设置增加默认开启的“开始串流时自动将游戏置于前台”；手机增加“游戏置前”。只在启动或点击时请求一次，不持续抢焦点。Windows 拒绝时提示手动点击游戏窗口。
- 启动串流隐藏本模块面板，并通过公开 ImGui API 清除插件窗口输入焦点，避免文本输入窗口继续捕获电脑键盘。该因素是潜在原因，尚未实机确认是本次实体键盘异常的根因。
- 修复横屏全屏时原页面标题、设置和按钮覆盖视频；悬浮视频区域挖空下面页面，避免透出文字和点击目标错位。
- 增加授权会话输入计数与焦点诊断，便于区分纯采集异常和手机输入干扰。

验证：服务端编译与模块生命周期/来源兼容通过；44 项模拟输入检查通过（未向真实游戏注入按键）；浏览器回归通过，覆盖只看无输入、慢网络合并、过期回复、鼠标拖动/取消不点击、全屏页面隐藏与悬浮窗布局；APK 签名与资源一致性检查通过。

用户确认仅采集正常，碰过手机控制后电脑键鼠才开始异常，支持继续集中核查输入注入路径。实体电脑键鼠、手机触控和实际网络表现待更新后验证，未宣称已实机排除全部干扰原因。采集组件本次未变更。
