# 狒狒食柿 0.3.50 验证版

App 与服务端均使用 0.3.50，使用 Omni 1.1.6.8 验证编译。安装标识、签名和统一授权保持兼容。

- 同一地址与端口的连接按授权凭据和游戏角色身份分别保存；原记录迁移后保留名称和凭据。选择保存的角色时，电脑实际角色不同会明确报错。账号设置增加删除账号按钮。
- 修正特殊货币映射，补齐军票、兵团徽章、巧手及大地票据。军票按当前军队读取，数量及上限取游戏公开接口。
- 角色参数保留独立页面，模型与装备移到“人物”页。模型手动开启，静止时只保活；拖动合并请求，退出页面和游戏登出清理预览。批量图标解码移出游戏主线程。游戏偶发未响应是否完全解决仍需实机观察。
- 坐骑与宠物采用五列、每页三十格的图标分页，支持名称搜索与手机收藏。
- 兵装库、物品与陆行鸟鞍囊统一使用方形槽位。空格不再继承聊天空状态的上边距；主题按钮不会覆盖槽位形状，保留实际游戏排序及空槽位置。
- 串流控制增加隐藏按钮，小窗与分屏均可重新打开控制。修正初始布局为画面上方、控制下方。
- 增加目标帧率 10/30/60 FPS、码率上限 2M/8M/20M 与触屏/鼠标指针模式。帧率、码率在停止后调整；输入模式可切换。采集组件按目标节流并动态调整 JPEG 质量，服务端不重复发送旧帧。
- 鼠标输入沿用统一授权、当前串流会话及前台游戏限制，支持画面坐标映射；失焦、停止、授权撤销或心跳超时释放按钮。

## 验证范围

源码编译、模块生命周期、16 项招募解析、26 项按键/鼠标状态检查、账号身份分离与浏览器界面回归通过。APK 内容与源码一致且沿用原签名。

独立采集组件在当前电脑游戏窗口的短时采样：10 FPS/2M 约 8.6 FPS，30 FPS/8M 约 19.3 FPS，60 FPS/20M 约 32.5 FPS；这是采集测量，手机接收帧率另受网络与解码影响，界面显示实际接收帧率。60 FPS 为目标值。

新服务端的货币数量、手机账号迁移/删除，以及游戏未响应改善尚待安装后实机核对；不将本地回归等同于这些实机结论。
