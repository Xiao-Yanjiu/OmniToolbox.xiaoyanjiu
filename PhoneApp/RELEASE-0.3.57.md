# 狒狒食柿 App 0.3.57 验证版

本次仅更新 App；服务端保持 0.3.55，采集组件及 FFmpeg 不变。

- 修复鼠标指针在移动结束后再次跳动：移除手机端预测指针，仅使用电脑反馈的实际位置绘制，避免预测与Windows鼠标速度/加速造成的位置差异在收尾时被二次校正。
- 显示坐标与相对输入累计坐标分开；位置反馈不修改待发送的相对坐标，不触发系统鼠标输入。
- 鼠标移动请求确认后立即请求刷新实际指针，减少仅靠250毫秒轮询带来的反馈等待。状态请求只保留一个在途请求，后续刷新合并，避免积压。
- 保留触屏模式隐藏指针、小窗独立标题/缩放条、透明映射面板与自动控制。

验证：浏览器回归覆盖预测指针不绘制、真实反馈单次更新、松手后无定时二次校正、反馈不注入移动、状态刷新合并和既有串流布局。签名安装包及资源一致性校验通过；实际手机效果待核对。

该修复处理用户确认的手机白色指针显示跳动，未将其描述为电脑真实鼠标再次移动。没有更换传输协议或宣称降低视频端到端延迟。
