# 保留现有模式：CPU 幻化预览编码 / 模块内部版本 1.4.4

这是功能保留版，不是禁用预览版。交付文件继续沿用原地址，没有创建另一套模块或版本目录。APK 沿用已交付的 0.3.109-local；需更新原地址的 OmniGlamourPreview.dll 和 PhoneChat-0.3.108.cs。

## 当前实现

幻化人物仍由游戏原生试衣间渲染。仅使用 SDK 的 GetRawImageAsync 做一次原尺寸像素快照；不再从后台任务创建 GPU 缩放纹理，也不再调用纹理 WIC 编码。快照完成后释放持有的纹理视图引用，后续缩放、通道转换和 JPEG 编码只操作自有 CPU 字节数组。
编码任务至多一个在途，支持取消、代次检查和超时。对原生纹理每帧重新核验可用状态、视图地址与尺寸；不再因为原生纹理对象地址没变就持续使用旧视图。

预览和游戏串流各有连接、任务、停止信号与资源清理；删除了串流请求预览暂停/恢复的联动。游戏画面串流仍使用用户原来的模式、分辨率调整、帧率与操作流程，没有改为另一种串流模式。保留所有预览控制、数据管理和手机功能。

CPU 方案能减少预览额外 GPU 缩放与编码负载；不能消除人物渲染和像素复制的 GPU 使用。目标仍为流畅预览，但未在当前电脑和手机上实测 FPS，不能保证 CPU 编码已达到稳定 30 帧。

本地模块及完整集成源码编译零警告零错误，76 项托管/CPU 图像检查通过；服务端编译通过。测试包括 BGRA/RGBA 色彩、透明度处理、像素边界与取消；没有运行游戏、GPU 读回或并发串流复现。

建议在游戏完全退出后替换原文件，再重启加载；不要依靠热切换清除旧版本已提交的 GPU 工作。现有数据与配置保留。
