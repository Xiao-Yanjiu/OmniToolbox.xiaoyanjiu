# 狒狒食柿 0.3.58 验证版

需同时更新 App、服务端和硬件串流组件 StreamHost.exe。FFmpeg 沿用原 8.1 组件；新组件由模块下载按钮下载并校验后手动选择，不会替换正在运行的组件。

- 修复竖屏控制板重叠：左右摇杆独立一行，数字、鼠标及功能键在下方排列；小窗和分屏支持滚动，保留隐藏按钮与透明背景。
- 新增加密 UDP 视频传输，默认 UDP 18766；原 HTTPS/TCP 端口保持不变。公网需要映射 UDP 外部端口到电脑的 UDP 端口并放行防火墙；局域网无需路由映射。支持单独填写 UDP 地址/端口，以及明确选择 TCP 兼容模式。当前支持 IPv4，无自动打洞。
- UDP 使用每连接独立 AES-GCM 密钥、双向验证、防重放、有限纠错与有界缓冲；不可恢复的帧等待下一关键帧。持续丢包时 20M→8M→2M 降码率，避免无限积压。所选码率为编码码率，纠错和协议另有带宽开销。
- 新增 GPU 直接采集：游戏窗口 D3D11 纹理送入硬件编码，去掉旧路径的应用层 CPU 像素回读。模块可关闭 GPU 直接采集以使用 CPU 兼容路径。保留显卡选择，不自动改用软件编码。
- 修复视频显示 Surface 重建后的接收恢复。

验证：服务端 SDK 编译、57 项模拟输入检查、模块生命周期检查、34 项 .NET UDP 检查和 50 项 Java 恢复检查通过；真实 GPU H264 经 UDP/Java 接收后解码成功；浏览器布局回归与签名 APK 校验通过。RTX 3090 Ti 实测 GPU 路径及运行中降码率可用；AMD/Intel 路径尚无实体硬件验证。

本机 GPU 路径约 48 FPS，与同期 CPU 路径相近；未实测手机端到端延迟或公网效果，不保证固定 60 FPS。这不是 Sunshine/Moonlight 协议。实现、协议及依赖许可说明见 PhoneApp/STREAMING.md。
