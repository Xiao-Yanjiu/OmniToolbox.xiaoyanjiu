# 狒狒食柿 0.3.53 验证版

请同时更新 App、服务端；在服务端面板“串流设置”点击“下载硬件串流组件”更新采集组件。已有 FFmpeg 可继续使用。

- 删除“角色 → 人物”二级栏、手机人物预览实现和服务端打开原生角色窗口的代码。旧客户端的人物预览接口明确返回已移除，不再打开游戏角色框。
- 修复 H.264 有解码帧率却不显示画面：原生视频层上方的网页 `html` 背景原先仍不透明，现与 `body` 一起透明，停止时恢复。
- 修复原生视频启动时屏幕尺寸变化导致未连接视频的问题；横屏、小窗和分屏调整显示区域时沿用当前视频尺寸，避免触发采集器重建。
- 采集使用高精度时钟和带容差的目标帧率调度，避免整数毫秒限帧将接近60Hz的帧流误丢；持续消费最新捕获帧，替换过期候选帧，不在忙碌期间积累旧画面。
- 使用可回收像素缓冲区，降低大数组反复分配；手机解码只在恢复关键帧时重置，使用当前显示时间提交最新输出。
- 超宽游戏窗口按比例限制到最大3840×2160再编码，并向手机报告实际编码尺寸，保留宽高比。
- 手机状态同时显示目标帧率与实际解码帧率；60FPS是目标，不会凭空补出游戏没有输出的帧。

验证：浏览器回归覆盖原生视频所需的html/body透明与四个保留角色二级栏；7项高精度限帧检查通过。服务端编译、源码兼容、输入/权限队列检查、APK签名检查通过。

当前服务端0.3.52已实测收到10个H.264视频包且能解码；用户截图亦显示约29FPS解码，支持显示层被遮挡的定位。新版组件在本机RTX3090Ti、5120×1368游戏窗口、目标60FPS/8M下短测输出约55.1FPS，源采集约55FPS、读回约15ms，编码尺寸3840×1026，首帧约637ms。该数据不含手机网络与显示延迟；未保证所有设备或网络达到60FPS，实际手机显示修复待更新后核对。

硬件编码来源与许可见 [串流说明](https://github.com/Xiao-Yanjiu/OmniToolbox.xiaoyanjiu/blob/main/PhoneApp/STREAMING.md)。下载按钮只有用户点击后才下载并校验，不自动启用或启动串流。
