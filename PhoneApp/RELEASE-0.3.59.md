# 狒狒食柿 0.3.59 验证版

需更新 App 和服务端；StreamHost 保持0.3.58，FFmpeg不变。

- 新增「国服频道（脱机使用）」页面：聊天与招募可横向切换，手机直连 Omni 官方开放接口，不依赖游戏或电脑模块在线。
- 账号设置可添加仅保存接口令牌的脱机账号，也可为已有账号配置令牌。用户在Omni中自行生成OST_令牌后手动填写，App不生成、不重置、不自动读取剪贴板；按账号加密保存，令牌不进入网页脚本。
- 聊天支持5秒增量轮询、游标失效恢复、去重、500 Unicode字符单行发送、化名提及、限流等待与超时读取确认。重试保留消息编号，避免自动重复发送。
- 招募支持实时/固定/全部、分类计数、列表分页、详情、职业限制、评论及评论分页。接口没有提供发布、申请或评论写入操作，未添加这些操作。内容标注来源并按文本显示。
- 串流模式统一在服务端选择TCP或UDP：TCP无需额外端口；UDP需填写端口，可另填公网外部端口。App移除协议/IP/端口输入并自动采用服务端配置，沿用账号连接地址，清除旧的手动覆盖。
- 下载必要组件合并为一个按钮，两项都校验通过后统一填写路径。删除指定的面板说明，显卡选择与刷新按钮同排。
- 竖屏功能键位于上方、两个摇杆位于下方；修复错误文字挤窄按钮。错误面板持续显示，不再被停止回调覆盖；组件过旧时明确名称、版本和下载入口。

验证：官方公开聊天、招募列表及详情只读连通核对；浏览器使用模拟数据覆盖授权门禁、账号隔离、文本转义、游标恢复、发送超时确认和招募评论分页。服务端SDK编译、输入状态/协议配置、下载校验和模块生命周期检查通过。APK原签名及资源一致性校验通过。未向真实国服频道发送测试消息，实际手机脱机发送待用户令牌验证。

串流组件下载：[StreamHost.exe 0.3.58](https://github.com/Xiao-Yanjiu/OmniToolbox.xiaoyanjiu/releases/download/phone-v0.3.58/StreamHost.exe)。
