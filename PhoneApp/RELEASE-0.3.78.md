# 狒狒食柿 0.3.78

App与游戏内服务端配套升级。Android versionCode 59，包名与原签名保持不变，可覆盖安装。

从公开版0.3.62以来的主要更新：
- 新增Omni物品查询与收录：搜索、详情、收藏、获取途径、来源地图、全区服务器价格与市场板，购买仍需明确确认。数据经游戏服务端桥接Omni，手机不直接连接Omni。
- 国服离线模式默认断开，单按钮加入/退出，聊天与招募共享状态，加入加载近期历史，退出清空显示。
- 新增“鱼糕”：原站页面嵌入，服务端持久化提醒计划，支持App、QQ/推送和自动路由；测试通知有服务端回执，系统文件选择与保存接通。
- 新增“灰机Wiki”，支持App内浏览、返回/刷新和外部浏览器。站点安全验证可能限制WebView访问。
- 服务端编辑导航排序和开关，手机同步且不再编辑；两项Omni物品页面缺少运行中的Omni时不能启用。

安装：
1. 安装本Release的FeifeiShisi.apk。
2. 在Omni在线模块更新“狒狒食柿《服务端》”至0.3.78，或手动加载同版PhoneChat.cs，再重载模块。
3. 鱼糕顶部“手机提醒”选择发送方式并发送测试。QQ/WxPusher/Server酱沿用电脑端配置。服务端须保持运行；App直连通知仍需手机通知与后台权限。
4. StreamHost沿用0.3.58，无需为本版更换。

校验：APK与服务端SHA-256见SHA256SUMS.txt，在线模块清单和App更新清单使用同一份发布产物的散列。
验证：两端编译，Android v2/v3签名与资源一致性；完整手机UI回归；33项服务端计划/路由/回执/导航检查，53项物品/报价/购买边界与10项手机提醒数据校验；原站实际测试按钮、导出重新导入、鱼类窗口订阅桥接。自动化未向真实QQ或推送服务发送消息。
限制：真机系统文件窗口、横幅与锁屏通知、真实游戏购买/外部通知投递仍需实机确认。鱼糕后台计划当前覆盖鱼类开窗，每鱼最多32窗口、最远30天，重新打开更新后续计划；不宣称海钓航线离线规划。Wiki验证由原站决定。
