# 狒狒食柿 0.3.55 验证版

请同时更新 App 和服务端。继续使用 0.3.53 硬件串流组件及已有 FFmpeg，无须下载新组件。

- 串流期间自动启用手机操作；“控制”仅展开/隐藏映射面板，隐藏后仍可直接操作画面。失去游戏前台、断线时释放输入；恢复后自动重新启用，不重放旧按键。
- 控制区底色完全透明，空白区域透过触摸到游戏画面，只保留按钮和摇杆。全屏摇杆加大；ESC、空格、M、1、0 位于2468下方。
- 添加可按住的鼠标左键、右键和滚轮上下按钮。触控与鼠标左键共用状态，避免一个控件提前释放另一个仍按住的左键；滚轮计数避免网络合并时漏步或重复滚动。
- 添加“输入法”按钮，弹出 Android 原生输入框及键盘，支持中文等 Unicode 文字。先点选游戏聊天输入框，再确认填入；不自动发送聊天，不自动按回车。确认后只提交一次，避免重试导致重复输入。
- 手机持续显示服务端返回的真实鼠标位置，无须先触摸画面；保留现有硬件组件，避免重新下载大型采集器。
- “游戏置前”独立于串流进程，串流停止后仍可使用。Windows拒绝置前时仍需手动点击游戏窗口。
- 视频连接中断后有限重试，重新等待关键帧；网络重连期间暂停并释放输入，解码恢复后自动启用。服务端不再因4秒暂时无视频帧直接退出，单次发送超时由750毫秒调整到2.5秒；保留15秒无心跳清理。
- 新增小型断流诊断记录与状态检查，区分采集器退出、网络I/O中断和视频发送超时。

验证：服务端编译、模块来源兼容及生命周期检查通过；57项模拟输入/视频I/O故障检查通过，未向实际游戏注入测试按键。浏览器回归覆盖透明透触、放大摇杆、映射面板隐藏后继续控制、左右键与滚轮、输入法按钮、光标反馈和停止后置前；签名安装包与资源一致性检查通过。

本次旧版服务端只确认串流已经停止，旧版未保存断线原因，无法追溯确认该次中断来源。真实手机的重连、系统输入法及游戏文字输入效果待更新验证；Unicode注入需游戏输入框接收，不承诺对所有游戏输入框有效。
