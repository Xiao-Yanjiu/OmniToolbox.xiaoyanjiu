# 狒狒食柿服务端 0.3.52

仅更新服务端模块，手机 App 保持 0.3.51。

- 硬件串流设置移入“狒狒食柿《服务端》”面板的独立“串流设置”折叠栏，默认收起。模块选择页只保留打开面板的按钮。
- 提供“下载硬件串流组件”“下载 FFmpeg”按钮。用户点击后才开始下载，显示 MB 进度，可取消；校验固定 SHA256，失败时保留原配置，成功后填写本地路径，FFmpeg 自动解压。
- 下载保存到独立目录，不覆盖正在使用的组件；不自动勾选硬件模式或开始串流，下次主动开始串流时使用新路径。
- 路径字段增加可见标题和提示，保留手动路径、显卡选择和刷新列表。

继续复用0.3.51硬件组件及固定 FFmpeg 8.1.3 LGPL 构建；来源和许可见 [硬件串流说明](https://github.com/Xiao-Yanjiu/OmniToolbox.xiaoyanjiu/blob/main/PhoneApp/STREAMING.md)。手机安装包见 [0.3.51 发布页](https://github.com/Xiao-Yanjiu/OmniToolbox.xiaoyanjiu/releases/tag/phone-v0.3.51)。

验证：服务端编译与源码兼容检查，本地 HTTP 的成功下载、错误摘要、大小限制、取消检查通过。此验证不执行下载程序；游戏中折叠栏与实际组件下载仍待加载后核对。
